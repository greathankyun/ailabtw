# 星航者 StarVoyager 行銷文案與發文指南

網址：https://starvoyager.pages.dev
一句話定位：**免費、免下載的 1:1 真實尺度太空探索遊戲，打開瀏覽器就能駕駛太空船飛遍真實宇宙。**

## 核心賣點（所有文案共用）
1. **1:1 真實尺度**：行星位置依 NASA JPL 軌道根數即時計算，此刻在哪，遊戲裡就在哪。
2. **真實星空**：Hipparcos 星表約 1.9 萬顆恆星、88 星座；地球晝夜與台灣時間同步，晚上看得到台灣城市燈光。
3. **31 艘太空船**：奧林帕斯艦隊＋深空探索艦隊，各有不同性能。
4. **101 個任務、7 章、11 級階級**：登陸月球、穿越土星環縫、追上航海家 1 號、飛往比鄰星 b。
5. **宇宙的故事**：19 章，台灣口音語音旁白，從大霹靂飛越 138 億年。
6. **星際遊覽車**：19 站自動飛行導覽，適合掛著欣賞、親子一起看。
7. **一台當螢幕、一台當遙控器**：掃 QR Code，手機變駕駛艙。電腦、手機、平板都能玩，可安裝成 App。

1. **給我 OpenAI API key**：我可以直接呼叫 OpenAI 的圖像模型（gpt-image）產圖，再幫你排版加字。建議把 key 設成環境的機密變數，不要直接貼在對話裡。費用由你的 OpenAI 帳號計算。
